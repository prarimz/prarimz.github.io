Moomin Privacy Policy

Moomin is the levelling, activity and moderation bot for the Jay Nepal Discord server. This page says exactly what it records about you, what it never touches, who else sees any of it, and how to switch the whole thing off.

Last updated 19 September 2026 Applies to the Moomin bot in Jay Nepal Operator the Jay Nepal server owner

The short version

  • Moomin counts what you do. It does not keep what you say.
  • Your messages are read as they arrive so the bot can award XP and catch spam, then discarded. The text is never written to the database.
  • One feature sends message text outside the server: >roast, which passes up to 50 of the target's recent messages to Google's Gemini API. Nothing else leaves.
  • Run >privacy off and Moomin stops recording anything about you from that moment. Run >privacy delete and everything already held is erased.
  • Moderation records are the one exception, and they are not yours to switch off. See section 8.

Everything below is attached to your Discord user ID. No names, emails, IP addresses or payment details are collected, because the bot has no way to see them and no use for them.

02Why Moomin needs to read messages

Discord calls this the Message Content intent, and it is the most sensitive permission the bot holds, so it is worth being precise about it.

Moomin reads the content of messages in the server for four things: awarding XP for genuine participation rather than one-word spam, detecting emoji, sticker and reaction spam so it can warn or restrict repeat offenders, answering commands that begin with >, and picking a daily Featured Quote.

In every one of those the text exists only for as long as the check takes. What survives is a number: your XP went up, your message count for today went up, an offence was recorded. The sentence itself is gone.

Two deliberate exceptions, both of which store text you wrote on purpose rather than in passing:

  • Reports. When you report someone, the reason you type is kept with the report, up to 1,500 characters, so moderators can act on it.
  • Direct messages to the bot. DMs sent to Moomin are forwarded to a private staff channel so the team can answer them. Do not send the bot anything you would not send the moderators.

03Where it is stored

All of it sits in a single PostgreSQL database hosted by Supabase, which encrypts data at rest. The bot itself runs on a private virtual server. Access to both is limited to the server owner.

The database holds no credentials of yours, because you never give the bot any. There is no account to sign into, no password, and nothing to breach on your side.

04Who else sees it

Your data is not sold, rented, or shared with advertisers, and there is no analytics or tracking product attached to any of it.

Google (Gemini API)

The >roast command is the only feature that sends message text off the server. When somebody roasts you, up to 50 of your recent public messages in the server are sent to Google's Gemini API to write the reply. They are sent at the moment of the request and are not stored by Moomin before or after. Google's handling of them is governed by Google's own API terms.

If you would rather that never happened, >privacy off makes you un-roastable, and the command refuses by name.

Everyone else the bot talks to

Moomin also fetches football fixtures, Nepali calendar dates, market odds and GIFs from third-party APIs. None of those requests contain anything about you: they are lookups for public information, identical no matter who triggered them.

Server staff

Moderators can see reports, warnings, automod offences and the leaderboards. That is the job.

05How long it is kept

Moomin is a levelling bot, so most of what it holds is meant to last: a rank that quietly reset every month would not be a rank. Nothing is kept on a 30-day cycle.

06Your controls

Four commands, usable by anyone, with no need to ask a moderator first.

>privacy Shows exactly what is held on you right now, counted from the live database rather than described from memory.
>privacy off Stops collection entirely: no XP, no activity history, no channel counts, no quests, no social graph in either direction, never picked for Featured Quote or On This Day, and never roastable.
>privacy on Starts again from that moment. Nothing from the opted-out period was kept, so there is nothing to restore.
>privacy delete Permanently erases your record, and strips the connections naming you from every other member's record too. Asks for confirmation first, and cannot be undone.

Opting out is applied at the point of collection. Moomin does not record your activity and then hide it. The check runs before anything is written, so an opted-out member leaves nothing behind to forget about later.

07Leaving the server

Your record is not deleted automatically when you leave, so that returning members keep their rank rather than starting over. If you want it gone, run >privacy delete before you go, or ask using the contact below afterwards.

08The moderation exception

Warnings, automod offences, and reports filed about you are not covered by the opt-out and are not removed by >privacy delete.

These are a safety record belonging to the server and to the members who filed them, not personal data belonging to their subject. A delete command that cleared your own file would make it useless to everyone it exists to protect. Everything else is yours to erase.

09Age

Discord requires all users to be at least 13, and older in some countries. Moomin is available only inside one Discord server and inherits that requirement. It does not knowingly hold data on anyone below the minimum age for their country; if you believe it does, use the contact below and the record will be removed.

10Changes to this policy

If what the bot collects changes, this page changes with it and the date at the top is updated. A change that widens what is collected will be announced in the server rather than made quietly.

11Contact

For anything this page does not answer, for a deletion request you cannot make yourself, or for a complaint about how your data has been handled:

  • Run >privacy in the server, which handles most of it instantly.
  • Message a moderator in the Jay Nepal Discord server.
  • Email the server owner at [add your contact email].

Deletion requests made by email are actioned manually and confirmed back to you.
